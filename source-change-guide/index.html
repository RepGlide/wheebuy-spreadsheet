Source Change Guide

Stop reusing old notes when a link jumps, a page changes, an option disappears, or a label no longer matches.

Old notes go stale

A note from an old page is not a current fact. When the source changes, stop reusing the note and look again.

Link jumps

The link lands somewhere different from before. The old destination is gone — record the new one.

Page structure changes

The page layout changed. The option you noted may no longer be where it was.

Option disappears

A color, size, or version is gone. The old option is no longer current.

Old label no longer matches

The label in the sheet does not match the page anymore. The label is stale, not the page.

?Open item: is any old note being reused without a fresh look at the page?

A worked change

  1. Old note: a size was selectable last time.
  2. Now: the size is gone from the page.
  3. Action: stop reusing the note and recheck.
