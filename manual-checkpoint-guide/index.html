Manual Checkpoint Guide

Recheck the source page, exact option, current value, and final destination by hand.

Hollow nodes, not checkmarks

Each checkpoint stays open until you look at it on the actual page. The sheet cannot fill them in for you.

1. Source page

Which actual page is the information from? Open it and read where the link lands, not where the label points.

2. Exact option

Which option is selected on the page — the color, size, version, or quantity you are actually choosing?

3. Current value

What currency, quantity, time, and conditions does the number sit next to? A bare number is not a value.

4. Final destination

Where does the link or jump finally arrive? The final page, not the first one, is what you act on.

?Open item: have all four checkpoints been done on the actual page?

A worked checkpoint

  1. Source page: the link opens a listing page.
  2. Exact option: the size you select is confirmed there.
  3. Current value: the price and its currency are re-read.
  4. Final destination: the jump lands on the order page.

Static teaching board — no automation, live status, verification, or saved activity.
